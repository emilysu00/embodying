How to Install and Use the Focus App

Installation

1. Download and unzip the provided ZIP file.
2. Open Google Chrome and go to chrome://extensions.
3. Click Load unpacked and select the extracted folder.
4. Once installed, click the Focus extension icon to open the web app in a new tab.

Keyboard Shortcuts
You can use the following shortcuts to simulate different behaviours and trigger notifications, even while browsing other websites.

- Alt + Shift + 1 → Bored
- Alt + Shift + 2 → Tired
- Alt + Shift + 3 → Distracted
- Alt + Shift + 4 → Finish

Note
Keep the Focus tab open while studying. You can switch to other browser tabs, and the study timer will continue running in the background.
